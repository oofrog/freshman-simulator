# 신입생 시뮬레이터 확장 (개발 안내)

실제 수강신청 화면 위에 튜토리얼·실전 재현·팁을 덧씌우는 크롬 확장. **실제 신청은 되지 않는다.**

## 원칙 (모든 파일 공통)
외부 요청 금지와 `chrome.*` 사용 위치는 PR마다 자동 검사(`node scripts/check.js`)가 확인한다.
- 외부 서버 연결 금지: `fetch`, `XMLHttpRequest`, `WebSocket`, `sendBeacon`을 쓰지 않는다 (LLM 포함).
- 페이지 글자는 `textContent`로만 넣는다. `innerHTML`에 페이지 데이터를 넣지 않는다.
- 학교의 제한(새로고침 차단, 대기열, 매크로 방지)을 건드리지 않는다.
- 실제 화면 테스트는 수강신청 기간이 아닐 때만 한다.

## 실행
- **목업에서 (평소 개발)**: 레포 폴더를 VS Code로 열고 `mock/index.html` 우클릭 → **Open with Live Server**
  (또는 레포 폴더에서 `npx live-server`). 저장할 때마다 자동 새로고침된다.
  - 주소 뒤에 `?sg`를 붙이면 열자마자 확장이 켜지고, `?sg=모드이름`이면 그 모드까지 시작한다.
  - 처음 방문하면 첫 진입 안내가 뜨고, 닫으면 확장이 켜져 패널이 열린다(`?sg=모드이름`이면 그 모드 시작). 안내는 브라우저마다 한 번만 뜬다 (`localStorage`의 `mock-notice-seen`).
    예: `/mock/index.html?sg=practice`, `?sg=tutorial`, `?sg=tip`
  - 수동으로 쓸 때는 화면 오른쪽 위 파란 **확장 켜기** 버튼. 브라우저 툴바의 확장 아이콘과 같게 동작한다 (누르면 그 자리에 패널이 뜨고, 바깥을 누르거나 Esc로 닫는다).
- **크롬 확장으로 (가끔 최종 확인)**: 아래처럼 로드한 뒤, 코드를 고치면 `chrome://extensions`의 ↻ → 페이지 새로고침 → 아이콘 → 팝업에서 모드 선택.
  목업에서 크롬 확장 아이콘을 쓸 때는 목업의 확장 켜기 버튼을 같이 누르지 않는다 (확장이 두 개 따로 뜸).
- **크롬 확장으로**: `chrome://extensions` → 개발자 모드 → 압축해제된 확장 프로그램 로드 → `extension/` 선택 → 아이콘 클릭 → 팝업에서 모드 선택. 크롬 확장은 모드 선택을 페이지 위 패널 대신 브라우저 팝업(아이콘 아래 창)으로 띄운다.
- **판정 스크립트**: 레포 폴더에서 `node --test` (Node 18 이상, 설치할 것 없음). `test/` 아래 `*.test.js`를 모두 돌린다.

## 튜토리얼 확인 방법
1. 목업에서 아무 메뉴나 연 뒤 확장을 켜고 **튜토리얼**을 누른다. 수강편람으로 이동해 `1 / 17`부터 시작한다.
2. 첫 단계에서 검색 조건을 바꿔 본 뒤 강조된 **조회**를 직접 누른다. 이후 말풍선의 **다음**으로 설명을 읽고, 메뉴 단계에서는 강조된 메뉴를 직접 누른다.
3. 오른쪽 진행 패널에서 진행 숫자·진행률·다음 동작을 확인한다. **이전**을 누르면 앞 단계의 화면으로 돌아간다.
4. 마지막 **완료**를 누르면 완료 안내가 나온다. 중간에 **그만하기**로 끝내고 다시 시작할 수 있다.
- 설명의 제목·본문은 `extension/tips.js`를 그대로 사용한다. 조작 안내는 진행 패널에만 표시한다.
- 대상 요소가 없는 화면에서도 화면 제목 옆에서 같은 설명을 읽을 수 있다. 메뉴 이동에 실패하면 **다시 시작** 또는 **그만하기**를 선택한다.
- 신청·추가·삭제·수강취소는 설명만 보여 주며 클릭은 막힌다.

## 모드 만드는 법
```js
SG.register('tutorial', {
  label: '튜토리얼',        // 패널 버튼 글자
  async start() { ... },    // 패널에서 눌렀을 때
  stop() { ... },           // [끝내기]·다른 모드로 바꿀 때 (화면에 바꾼 것 되돌리기)
  allow(el) { ... },        // (선택) true를 돌려준 요소는 클릭 허용. 없으면 페이지 클릭은 전부 막힘
  blocked(el) { ... },      // (선택) 막힌 클릭이 일어났을 때
  escape() { ... },         // (선택) Esc를 눌렀을 때. 있으면 core의 기본 닫기 대신 이것만 불림
});
```
- 패널은 확장 팝업처럼 동작한다: 아이콘으로 열고, 바깥을 누르거나(그 클릭은 막힘) 모드를 시작하면 닫힌다. 모드 없이 닫히면 확장도 꺼진다.
- 모드 중에는 위쪽 가운데 검은 상태 바(`모드 이름 중` + [끝내기])가 뜬다. [끝내기]·`SG.stop()`은 모드와 확장을 함께 끈다. 다시 쓰려면 아이콘.
- 모드가 상태 바 내용을 바꾸려면 `SG.bar({ text, buttons: [['글자', 함수], ...] })` (실전 재현의 카운트다운·[연습 끝내기]), 숨기려면 `SG.bar(false)` (튜토리얼), 기본으로 되돌리려면 `SG.bar()`. 모드를 시작하거나 끝내면 기본으로 돌아간다.
- Esc는 떠 있는 것만 닫고 모드는 끄지 않는다: 패널이 열려 있으면 패널, 아니면 모드의 `escape()`(자유 팁은 말풍선, 실전 재현은 메시지. 실전 재현 결과창에서는 [닫기]와 같아서 모드와 확장이 함께 꺼짐), `escape()`가 없으면 버튼이 하나뿐인 모달(그 버튼을 누른 것과 같음). 버튼이 여럿인 모달과 튜토리얼 말풍선은 닫지 않는다.
- 확장이 켜져 있는 동안 페이지 클릭은 기본적으로 **전부 막힌다**. 모드가 `allow(el)`로 예외를 줄 수 있고, 모드가 없을 때(패널이 열려 있거나 시작 실패 안내 중)는 예외 없이 전부 막힌다. 위쪽 메뉴, 표 아래 페이지 링크, 상세조회↔일반조회는 직접 눌러 보는 요소(`SG.tryable`)라 자유 팁 모드에서도 동작하고 팁이 뜨지 않는다.
- 확장이 만든 요소(`SG.el(...)`로 만든 것)는 막히지 않는다. 그 안에서 일어난 클릭 등은 페이지(학교 코드)로 올라가지 않는다.

## core가 주는 함수 (`SG.`)
| 함수 | 용도 |
|---|---|
| `screen()` | 지금 화면 이름 ('희망수업' 등) |
| `rows()`, `cell(행, '열 이름')`, `headers()` | 과목 표 읽기 (숨김 칸 자동 처리) |
| `findButton(범위, '신청')`, `buttons(범위)`, `label(el)` | 보이는 버튼 찾기 |
| `goMenu('희망수업')`, `waitFor(조건함수)` | 화면 이동과 대기 |
| `matchTip(el)`, `tipEl(tip)`, `tryable(el)` | 요소 → 팁, 팁 → 요소. `tryable`: 직접 눌러 보는 요소(위쪽 메뉴·페이지 링크·상세조회↔일반조회)인지. 이런 요소는 `matchTip`이 팁 없음(null)으로 본다 |
| `highlight(el, thin)`, `unhighlight()`, `bubble(el, {title, text, buttons})`, `modal({title, text, buttons})`, `clear()` | 오버레이. `highlight`는 기본 굵은 테두리(튜토리얼), `thin`이면 호버와 같은 얇은 테두리 + "?" 배지. `bubble`·`modal`은 누른 버튼 글자를 Promise로 돌려줌. `clear()`는 호버 테두리는 남김 |
| `hover(el)`, `quiet(on)` | 자유 팁용. `hover`: 마우스를 올린 요소에 얇은 테두리 + "?" 배지 (`null`이면 지움). `quiet`: 페이지 자체 `:hover`·마우스 올림 이벤트를 끄고 커서를 통일 (직접 눌러 보는 요소는 손가락 커서). 켜져 있는 동안 disabled 칸·버튼은 클릭을 부모로 넘겨 묶음·열 팁이 받는다 (켠 모드의 `stop()`에서 `quiet(false)`) |
| `el(tag, props, ...children)` | 확장용 요소 만들기 (클릭 차단에서 빠지고, 이벤트를 페이지로 올려 보내지 않음) |
